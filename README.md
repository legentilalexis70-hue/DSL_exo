# DSL_exo
J'ai utilisé le langage Brainfuck(https://esolangs.org/wiki/Brainfuck). J'ai eu du mal à trouver un langage implémenté et qui pouvait prendre quelque chose en input, donc après un temps de recherche conséquent, j'ai choisi ce choix de facilité.

Le programme peut être compilé ici: https://tio.run/#brainfuck.

Le gros problème est que l'entrée prise est en ASCII, j'ai donc du faire une conversion en entier, et dès que l'output est supérieur à 10, ça ne marche pas.
